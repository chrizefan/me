## About the Role

Guidewire is a leading insurance technology platform ($4B+ ARR) powering P&C insurance carriers worldwide. The Agentic AI engineer role sits within Guidewire's Data Platform products, building production AI systems for the insurance industry.

## Responsibilities

- Design, implement, and scale multi-agent AI systems and advanced RAG architectures powering production features across the Data Platform
- Design and operate multi-agent systems using LangGraph, LangChain, or similar frameworks
- Architect and optimize end-to-end RAG pipelines: document ingestion, chunking, hybrid search (semantic + keyword), retrieval-time re-ranking
- Build robust agentic loops using Python AsyncIO, concurrency control, timeout handling, graceful degradation
- Integrate with OpenAI, Anthropic, Gemini APIs and open-source models (Llama, Mistral)
- Work with vector databases (OpenSearch, Elasticsearch, Pinecone, Weaviate, PGVector)
- Cloud-native development on AWS/Azure/GCP with AI-specific services (e.g., Bedrock)

## Required Stack

- Python (expert, primary) — AsyncIO
- LangGraph / LangChain / LlamaIndex / AutoGen (at least one)
- RAG pipelines: vector stores, embeddings, chunking, hybrid search, re-ranking
- LLM APIs: OpenAI, Anthropic, Gemini + open-source models
- Vector databases (OpenSearch, Elasticsearch, Pinecone, Weaviate, or PGVector)
- Docker, Kubernetes, major cloud platform (AWS/Azure/GCP)
- TypeScript/Node.js (familiarity only, not primary)

## Required Experience

- 8+ years engineering experience
- Production distributed systems / APIs / data-intensive applications
- Multi-agent AI systems in production
